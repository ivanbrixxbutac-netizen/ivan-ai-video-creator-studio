
# Ivan AI Video Creator Studio

A mobile-friendly AI video creator interface.

## Features
- Video categories
- Select images and videos from your phone
- Preview selected media
- Video prompt input
- Aspect ratio and duration settings
- Demo project preparation screen

## Current limitation
This is a frontend demo. It does not generate real AI videos yet.

To enable actual generation, connect a supported video-generation API through a secure backend. Never put private API keys in `script.js` or other public frontend files.

## Run
Open `index.html` in a browser, or publish the repository with GitHub Pages.
